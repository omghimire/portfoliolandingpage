Computer Programming

कम्प्युटर प्रोग्रामिङ। Writing instructions a computer can follow, from a small script to a finished program.

Languages

A language is a way to write those instructions. Python, JavaScript, and others differ in syntax, but each one tells the machine what to do next.

Logic

Conditions and loops decide which step runs, and how many times, so the same program can handle different inputs.

Data

Variables hold a name, a number, or a list. A clear structure keeps one kind of fact from being mixed with another.

Functions

A function is a named piece of work. Calling it again avoids copying the same steps through the file.

Testing

Running the program on known examples shows whether the result matches what you expected before anyone else depends on it.
